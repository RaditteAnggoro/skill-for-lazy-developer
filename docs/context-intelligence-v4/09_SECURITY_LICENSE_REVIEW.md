# Security and license review

- The index accepts explicit files under a single canonical root. A refresh serializes cache writes and binds lookups and hydration to the caller's selected paths. It rejects symlinks, dot paths, common credential locations, oversized files, and known sensitive or instruction-like content. Detectors are heuristic. The SQLite cache may contain sensitive domain terms and identifiable paths. Treat it as project-private even though complete source bodies stay out of the index.
- Compaction stores original evidence separately and verifies its content identity on read. Capture only data permitted by the current task. Benchmark artifacts remain in ignored project-local paths or disposable directories.
- Recall requires an exact provider namespace and root fingerprint. Expired, unsupported, changed-source, and recognized injection records are excluded. Old unanchored records are historical context. Source and tool results remain data and cannot broaden authorization.
- MCP discovery requires a preconnected session, a local capability mapping, and authorization. It caps pagination and descriptor size, rejects external schema references, and ignores descriptive claims from the server. Invocation and output validation remain the caller's responsibility. The host chooses its actual transport, sandbox and approval policy. [MCP lifecycle](https://modelcontextprotocol.io/specification/2025-11-25/basic/lifecycle), [MCP tools](https://modelcontextprotocol.io/specification/2025-11-25/server/tools).
- The comparison reviewed pinned upstream files without installing services or uploading private data. This change imports no upstream source or skill text. The source register links to licenses present at the inspected revisions. Where licensing is mixed or unclear, review component-level terms before any reuse. [Pinned source register](02_NEW_OPENSOURCE_RESEARCH.md).

The regression suite uses synthetic fixtures. No production database, external embedding service, or private project source was used in the live comparisons.
