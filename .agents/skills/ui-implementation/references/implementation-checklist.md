# UI implementation checklist

- Reuse existing tokens, primitives, and patterns.
- Preserve labels, hierarchy, and settled interaction decisions.
- Implement keyboard focus, activation, and logical order.
- Implement empty, loading, error, disabled, and permission-limited states.
- Verify narrow and wide viewport behavior.
- Avoid horizontal overflow and layout shift.
- Keep financial and destructive confirmations explicit.
- Add focused interaction tests; avoid brittle snapshots for static markup.
- Report build, browser, and interaction evidence separately.
